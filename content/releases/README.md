Intentionally empty: no qualified clinical approval exists. Do not place synthetic test fixtures, unsigned AI teaching, the 60 legacy drafts or claimed credentials here.

Future files use `release-id.vVERSION.json` and the strict contract in `scripts/content-safety.mjs`. Run `npm run test:content` and `npm run check:content`.
